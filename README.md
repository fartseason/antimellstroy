# 🛡️ Anti-Scam & Anti-Phishing Discord Bot

Автоматический Discord-бот для защиты серверов от скама, фишинговых ссылок, спама и вредоносных вложений. Бот использует систему **каналов-ловушек (Trap Channels)**, позволяющую мгновенно выявлять и нейтрализовать спам-ботов и злоумышленников.

---

## 🚀 Основные возможности

* **🚨 Канал-ловушка (Trap Channel):** Автоматическое создание спецканала. Любое сообщение от обычного пользователя в этом канале приводит к немедленному наказанию.
* **⚡ Гибкая система наказаний:** Возможность выбора действия за нарушение:
  * 🔨 **Бан** (с удалением истории сообщений за последние 24 часа)
  * 👢 **Кик**
  * ⏱️ **Тайм-аут** (с гибкой настройкой длительности)
* **📋 Подробное логирование:** Запись всех инцидентов в закрытый административный канал (с сохранением текста сообщения, ID нарушителя, списка вложений и аватара).
* **⚙️ Настройка в один клик:** Управление параметрами защиты через интерактивные кнопки и слэш-команды (`/settings`).
* **🛡️ Изоляция прав:** Автоматическая настройка прав доступа к каналам безопасности при запуске.

---

## 🛠️ Стек технологий

* **Язык:** Python 3.10+
* **Библиотека:** `discord.py` v2.0+
* **Формат данных:** JSON (хранение настроек серверов)
* **Управление службой:** Systemd (для работы 24/7 на Linux VDS/VPS)
